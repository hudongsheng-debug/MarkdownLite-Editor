## MarkdownLite Editor Version 2.0.0

MarkdownLite Editor is a lightweight Markdown document editor for iOS, designed for users who want a simple, clean, and distraction-free writing experience.

The app focuses on essential Markdown editing and preview features without unnecessary complexity, making it suitable for quick notes, documentation, and plain text writing.

## Version 1.0 Features

**Markdown Editing**

	Edit Markdown (.md) files with a clean text editor
	Monospaced font optimized for writing
	
**Live Preview**
	Switch between Edit and Preview modes
	Render standard Markdown syntax for quick inspection
	
**Document-Based Workflow**

	Open and edit Markdown files directly from the Files app
	Supports opening documents in place
	Import and export Markdown files
	
**iCloud Drive Support**

	Works seamlessly with iCloud Drive
	Documents remain accessible across devices
	
**Universal App**
	Optimized layouts for iPhone and iPad
	
## Version 2.0.0 Features
**Synchronized Highlighting Between Editor and Preview**

Double-tap a paragraph in the editor to highlight the corresponding content in the preview. Double-tap the same paragraph again to clear the highlight.

**Improved Editor Font Size**

Increased the editor font size for clearer, more comfortable reading and long-form editing.

**Redesigned Toolbar Interaction**

Refined the toolbar layout and fixed an issue where the keyboard could not be dismissed properly, resulting in a smoother editing experience.

**Editor / Preview Layout Switching**

Added a one-tap option to swap the positions of the editor and preview, accommodating different workflows and screen sizes.

## Supported Markdown Syntax
	Headings
	Bold / Italic / Strikethrough
	Lists (ordered & unordered)
	Blockquotes
	Inline code and code blocks
	Line breaks and paragraphs
